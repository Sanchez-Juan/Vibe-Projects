# Fundamentos de Química Orgánica · Repaso

Sitio estático (HTML/CSS/JS, sin build). Guía, quiz (67 preguntas en 5 rondas) y ejercicio integrador; el progreso se guarda en el navegador.

- Probar local: abre `index.html` o corre `npx serve .`
- Editar preguntas: `data.js` (`QUIZ` y `EJER`).
- Vercel: importa el repo, Framework Preset **Other**, sin Build Command, Output Directory vacío (raíz).
